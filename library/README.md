# Thư viện âm thanh

Chép bản thu tiếng mưa vào các **thư mục con** ở đây. Mỗi thư mục là một nguồn âm thanh
cho một lớp trong Rain Mixer. Định dạng nhận: wav, flac, mp3, ogg, opus, m4a.

Gợi ý cách chia (tên thư mục tuỳ bạn, nên đặt không dấu):

| Thư mục | Nội dung | Kiểu lớp |
|---|---|---|
| `mai_ton/` | mưa trên mái tôn, mỗi file nên dài vài phút trở lên | nền liên tục |
| `mua_nen/` | mưa rơi đều ngoài trời, trên lá, trên đường | nền liên tục |
| `mua_cua_so/` | mưa gõ vào kính cửa sổ | nền liên tục |
| `mang_xoi/` | nước chảy từ máng xối, mái hiên | nền liên tục |
| `con_trung/` | tiếng côn trùng, ếch nhái đêm mưa | nền liên tục |
| `gio/` | tiếng gió, gió lùa qua cây, qua khe cửa | nền liên tục |
| `giot_nuoc/` | từng giọt nước rơi lẻ, mỗi file một giọt | âm rời rạc |
| `sam/` | tiếng sấm, mỗi file một tiếng | âm rời rạc |

Mẹo để bản mix nghe thật và mỗi bản một khác:

- Càng nhiều file trong một thư mục, các bản xuất càng ít trùng nhau.
- File nền nên dài (5–60 phút) và **không** có tiếng người, xe cộ hay nhạc.
- File âm rời rạc nên được cắt gọn, mỗi file đúng một tiếng sấm hoặc một giọt.
- Không cần chỉnh âm lượng trước: Rain Mixer tự cân bằng độ lớn giữa các file.

Chỉ dùng bản thu bạn được phép dùng cho video (tự thu, CC0, Pixabay…). Xem mục
"Thư viện tiếng mưa thu sẵn" trong README chính.
